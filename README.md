### Full-Stack Software Engineer

I'm a software engineer with a B.S. in Computer Science from the University at Buffalo. I build production software across two worlds: interactive web experiences and games for music and entertainment, and software for commercial building automation systems. I like debugging hard problems, shipping things real people use, and learning something new every day.

- 🌍 Based in New York, NY
- 🖥️ Portfolio: [mmushfiq.vercel.app](https://mmushfiq.vercel.app/)
- ✉️ Contact: [muhtasim01@gmail.com](mailto:muhtasim01@gmail.com)
- 🏢 Control Systems Software Engineer at **T.M. Bier & Associates**, building and debugging control software and JavaScript front ends for live commercial building systems (BACnet, Niagara)
- 🚀 Co-founder and sole engineer at **[Hyveout](https://www.hyveout.com/)**, a music-tech brand. I build the games and web experiences that connect artists with fans (100K+ game plays, 5M+ music video views)
- 🛒 Built **[A Witch's Whisk](https://awitchswhisk.com/)**, a full-stack e-commerce platform that generated $20K+ in revenue in its first 12 months
